# 지실 캘린더 (AntiFogWeb)

카카오톡 등 단체 메신저(9명)에 링크 하나만 공유하면 별도의 회원가입이나 앱 설치 없이 접속하여, 각자의 불가능한 일정을 체크하고 모임 날짜를 조율하는 웹 애플리케이션입니다.

---

## 주요 특징
- **간편 접속**: 링크를 누르고 본인 이름만 누르면 즉시 일정 입력 가능
- **고유 9색 팔레트**: 9명 각자에게 명확한 고유 컬러를 부여하여 달력 날짜 셀마다 누가 안 되는지 색상 도트로 직관적 시각화
- **불가 날짜 토글**: '불가 날짜 선택 모드'로 탭 한 번에 불가능한 날짜 등록/해제
- **실시간(Realtime) 동기화**: Supabase Realtime WebSocket을 통해 한 명이 날짜를 바꾸면 다른 8명의 화면에 즉시 반영
- **모바일 최적화**: 스마트폰 브라우저 환경에 최적화된 터치 UI/UX

---

## 9명의 멤버
1. 정인수
2. 서일훈
3. 한태환
4. 박상준
5. 이상재
6. 이찬빈
7. 그거
8. 이재훈
9. 정일환

---

## 1. Supabase 데이터베이스 세팅 (1분 소요)
1. [supabase.com](https://supabase.com)에 로그인 후 새 프로젝트를 무료로 생성합니다.
2. 좌측 메뉴에서 **SQL Editor**로 이동합니다.
3. 이 저장소의 `supabase/schema.sql` 파일 내용을 전체 복사하여 붙여넣고 **Run** 버튼을 누릅니다.
   - 9명 멤버 테이블(`members`) 및 불참 날짜 테이블(`unavailable_dates`)이 생성되고 위 9명의 이름이 등록됩니다.
   - 실시간(Realtime) 동기화 권한이 자동으로 활성화됩니다.
4. 좌측 메뉴 **Project Settings** -> **Data API** (또는 API)로 이동하여:
   - `Project URL`
   - `Project API Keys` (anon / public)
   를 확인합니다.
